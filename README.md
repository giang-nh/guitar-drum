# Guitar Drum

iPad-friendly static prototype for guitar practice with a simple drum accompaniment.

## Current prototype
- Song-aware drum playback for "Nàng Thơ"
- Tone transposition
- Tempo control
- 4-beat visual indicator
- Click any lyric/chord line to jump there
- 5-line focus view / show all
- Line numbering
- PWA-style install support

## Publish with GitHub Pages
1. If the repository is private and your GitHub plan does not support Pages for private repositories, change the repository visibility to **Public**.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Branch: **main**.
5. Folder: **/(root)**.
6. Save.

The site URL will normally be:

https://giang-nh.github.io/guitar-drum/

On iPad: open the site in Safari → Share → Add to Home Screen.

## Notes
This prototype is entirely client-side. No backend or database is required.
